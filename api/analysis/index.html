measurement ¶

measurement(
    spec_type: type[Analysis],

    | CoordFunc
    | None = None,
    depends: Iterable[Callable] | Callable = (),
    caches: Iterable[KwArgCache] | KwArgCache | None = None,
    store_compressed: bool = True,
    prefer_filtered: bool = True,
    prefer_aligned: bool = True,
    validate: AnalysisValidator | None = None,
    tolerance: AnalysisTolerance | None = None,
) -> AnalysisFuncWrapper[P]

register the decorated function as the measurement configured by spec_type.

The returned decorator adds an entry to this registry. The decorated function is called as func(x, capture, **spec.to_dict()) with x an array of shape (port, sample). The function returns an array with a leading port axis followed by dims, or an (array, attrs) tuple. The returned wrapper is called as wrapper(iq, capture, as_xarray=True, **kwargs) with the fields of spec_type as keywords. The __signature__ of the wrapper is filled from spec_type. The docstring placeholders are filled at registration: {args} from the fields of spec_type, {dtype} from dtype, {dims} with the dimension names of the output (port first), {coords} with one bullet per coord_factories entry, and {attrs} with one bullet per registered attr other than standard_name and long_name.

An array iq is passed to the function as x. From an AcquiredIQ, x is the waveform that AcquiredIQ.preprocess selects for prefer_filtered and prefer_aligned. validate runs before the IQ is read and raises specs.helpers.SpecValidationError on a rejected combination. A units in a power form (striqt.waveform.units.DB_POWER, POWER, or AMPLITUDE) is resolved into the power_units of the acquisition when the output is built. A literal unit such as the ratio 'dB' is stored as written. The fields of the spec and the attrs returned by the function are added to the registered attrs, and a key set in both takes the value from the function.

The wrapper returns, by as_xarray:

  • True: an xarray.DataArray with a leading port dimension
  • 'delayed': a DelayedDataArray
  • False: the (array, attrs) pair

Parameters:

  • spec_type (type[Analysis]) –

    the specs.Analysis subclass with the keyword arguments of the measurement as fields, registered once

  • dtype (str) –

    numpy dtype name of the output array

  • standard_name (str) –

    the short noun phrase that names the output on an axis, stored as the standard_name attr

  • long_name (str) –

    the sentence-case title of the measurement for a plot or a menu, stored as the long_name attr

  • units (str | None, default: None ) –

    the units of the output values, stored as the units attr, or None for a dimensionless output

  • dims (tuple[str, ...] | str | None, default: None ) –

    the dimension names of the output axes after port, or None for the dimensions that coord_factories declare, in order

  • coord_factories (Iterable[CoordFunc] | CoordFunc | None, default: None ) –

    functions registered with coordinates that produce the coordinate values along dims from (capture, spec)

  • depends (Iterable[Callable] | Callable, default: () ) –

    measurements with an intermediate that this measurement reuses, recorded on the AnalysisInfo entry and not otherwise read

  • caches (Iterable[KwArgCache] | KwArgCache | None, default: None ) –

    the KwArgCache instances that cache_context enables for one capture, shared with the other measurements that list the same cache

  • store_compressed (bool, default: True ) –

    False to store the output uncompressed in zarr

  • prefer_filtered (bool, default: True ) –

    False to measure the waveform before the analysis_bandwidth low-pass, where one is applied

  • prefer_aligned (bool, default: True ) –

    False to measure the waveform before the signal-trigger shift, where one is applied. A signal_trigger measurement must set False

  • validate (AnalysisValidator | None, default: None ) –

    a function of (capture, spec) that raises on a rejected combination without reading IQ, called with the specs.AnalysisCapture projection of the capture

  • tolerance (AnalysisTolerance | None, default: None ) –

    a function of (capture, spec, *, array_backend, input_error) that returns the specs.Tolerance of the output without reading IQ

  • AnalysisFuncWrapper[P] –

Raises:

    when spec_type is already registered

  • TypeError –

    when a coord_factories entry is not callable; from the returned decorator, when the function name is already registered or when caches contains something other than KwArgCache instances

cellular_5g_pss_correlation ¶

cellular_5g_pss_correlation(iq: Array | AcquiredIQ, capture: Capture, *, subcarrier_spacing: float, sample_rate: float = 7680000.0, discovery_periodicity: float = 0.02, frequency_offset: float = 0, shared_spectrum: bool = False, delay: float = 0, symbol_indexes: one of ['auto', 'a', 'b', 'c', 'd', 'e', 'f', 'g'] | tuple[int, ...] = 'auto', max_lag_symbols: int | None = None, max_block_count: int | None = 1, as_xarray: bool | Literal['delayed'] = True) -> Measurement

correlate each port of the IQ against the 5G NR primary synchronization signal.

The input is the IQ before the analysis_bandwidth filter and before trigger alignment. The band at frequency_offset is shifted to baseband and resampled to sample_rate. The result is cross-correlated with the PSS sequence of each cell sector ID (3GPP TS 38.211 §7.4.2.2). The PSS template has unit energy over the 127 PSS subcarriers. The squared magnitude of a peak on a lag sample equals the received PSS symbol power. White noise with power spectral density N0 has a mean squared magnitude of N0 * subcarrier_spacing in each lag.

Output
  • Array dtype: complex64
  • Dimensions: port, cellular_cell_id2, cellular_ssb_start_time, cellular_ssb_beam_index, cellular_ssb_lag

  • Coordinates:

  • cellular_cell_id2 (uint16): sector part of the physical cell ID of each sync template, 0 through 2

  • cellular_ssb_start_time (float32, s): start time of each sync block in the capture, in steps of discovery_periodicity, up to max_block_count blocks
  • cellular_ssb_beam_index (uint16): index of each candidate sync block in the burst set, in the order of symbol_indexes
  • cellular_ssb_lag (float32, s): lag of each correlation sample from the start of the IQ, from delay in steps of one sample at sample_rate, spanning max_lag_symbols OFDM symbols or the SSB when None

  • Attributes:

  • units: power units based on acquisition (√mW when calibrated)

  • noise_bandwidth: subcarrier_spacing (in Hz)
References

3GPP TS 38.211, "NR; Physical channels and modulation," Table 7.4.3.1-1 and §7.4.2.2. https://www.3gpp.org/DynaReport/38211.htm

3GPP TS 38.213, "NR; Physical layer procedures for control," §4.1. https://www.3gpp.org/DynaReport/38213.htm

cellular_5g_ssb_spectrogram ¶

cellular_5g_ssb_spectrogram(

    lo_bandstop: float | None = None,

evaluate a spectrogram of each 5G NR SSB burst set by OFDM symbol and subcarrier.

The input is the IQ before the analysis_bandwidth filter and after trigger alignment. The STFT hops once per OFDM symbol. Half-subcarrier bins are summed pairwise to one bin per subcarrier of subcarrier_spacing. Only the symbols of the burst set in the first 2 ms of each discovery_periodicity are kept (3GPP TS 38.213 §4.1).

Output
  • Array dtype: float16
  • Dimensions: port, cellular_ssb_index, cellular_ssb_symbol_index, cellular_ssb_baseband_frequency

  • Coordinates:

  • cellular_ssb_index (uint16): index of each burst set in the capture, one per discovery_periodicity, up to max_block_count burst sets

  • cellular_ssb_symbol_index (uint16): index of each OFDM symbol in the first 2 ms of the burst set, at subcarrier_spacing
  • cellular_ssb_baseband_frequency (float64, Hz): baseband frequency of each subcarrier relative to frequency_offset, in steps of subcarrier_spacing across the sample_rate band

  • Attributes:

  • units: power units based on acquisition (dBm when calibrated)

  • noise_bandwidth: subcarrier_spacing (in Hz)
  • resolution_bandwidth: equivalent noise bandwidth (in Hz) of the nonzero samples of window
  • limit_digits: 3, the decimal places of the rounding

evaluate cyclic statistics of channel power across the cycles in a capture.

The input is the IQ after the analysis_bandwidth filter and trigger alignment. Each power detector bins the capture on detector_period. The binned series is folded into cycles of cyclic_period. Each cyclic statistic reduces across the cycles (Kuester et al.). cyclic_period and detector_period alone set the trace length, independent of the capture duration.

A signal with a period that divides cyclic_period resolves at fixed lags with little spread between the 'min' and 'max' statistics. A cyclic_period of 10 ms covers TDD cellular frames, 5 ms covers WiMAX frames, and 1 ms covers the CBRS test bin 1 pulse repetition interval. The uplink and downlink levels of a TDD network then occupy disjoint lag windows. Occupancy with an incommensurate period smears across all lags.

Statistics are evaluated in linear power and converted to dB afterward. The capture duration must be a whole number of cycles. cyclic_period must be a whole number of detector periods. detector_period must be a whole number of samples at sample_rate. A detector_period written as a fraction stays exact, e.g., 1/28000 s for one OFDM symbol at 30 kHz subcarrier spacing. The noise bandwidth of the values is the analysis_bandwidth of the capture, or sample_rate where analysis_bandwidth is infinite.

  • Dimensions: port, power_detector, cyclic_statistic, cyclic_lag

  • cyclic_lag (float32, s): time from the start of each cycle, in steps of detector_period over one cyclic_period

  • units: power units based on acquisition (dBm when calibrated)
