striqt.figures¶

One plot function per measurement data variable, and the axis and legend labels derived from dataset coordinates.

cellular_5g_pss_correlation ¶

cellular_5g_pss_correlation(
    data: Dataset,
    plotter: _PlotBackend,
    *,
    hue: str = 'cellular_ssb_beam_index',
    dB: bool = True,
) -> Path | None

plot cellular_5g_pss_correlation of data as power against cellular_ssb_lag.

The values are the squared magnitude of the correlation in the first sync block (cellular_ssb_start_time index 0). The lower y limit is 7 dB below the smallest median power over lags of the hue values.

Parameters:

  • data (Dataset) –

    the dataset with the cellular_5g_pss_correlation variable and its cellular_cell_id2, cellular_ssb_start_time, cellular_ssb_beam_index, and cellular_ssb_lag coordinates

  • plotter (_PlotBackend) –

    the backend that draws the figure

  • hue (str, default: 'cellular_ssb_beam_index' ) –

    'cellular_ssb_beam_index' draws one line per beam index, averaged over cellular_cell_id2; 'cellular_cell_id2' draws one line per cell sector ID, averaged over cellular_ssb_beam_index

  • dB (bool, default: True ) –

    True draws the power in dB, False in linear units

Returns:

  • Path | None –

    the path of the figure file, or None when the backend writes no file

Raises:

  • KeyError –

    if hue is neither 'cellular_ssb_beam_index' nor 'cellular_cell_id2'

    data: Dataset,
    plotter: _PlotBackend,
    noise_line: bool = True,
) -> None

plot cellular_5g_ssb_spectrogram of data as a heatmap of symbol by frequency.

The first burst set of each capture (cellular_ssb_index 0) is drawn. The color scale starts 6 dB below the lowest system noise level over the captures, in 2 dB bands; without a system_noise variable in data the scale starts at the data minimum.

Parameters:

  • data (Dataset) –

    the dataset with the cellular_5g_ssb_spectrogram variable and its cellular_ssb_index, cellular_ssb_symbol_index, and cellular_ssb_baseband_frequency coordinates

  • plotter (_PlotBackend) –

    the backend that draws the figure

  • noise_line (bool, default: True ) –

    True marks the system noise level on the colorbar, from system_noise (dBm/Hz) of data in the noise_bandwidth of the variable; nothing is marked without system_noise

label_axis ¶

label_axis(
    which_axis: Literal['x', 'y', 'colorbar'],
    ax_data: Union[DataArray, Dataset],
    *,
    coord_name: Optional[str] = None,
    tick_units: bool | Literal['auto'] = 'auto',
    short: bool = True,
    ax: Optional[Axes | list[Axes]] = None,
    fig: Optional[Figure] = None,
) -> None

label an axis with the quantity and units named by the attrs of ax_data.

The label text is striqt.analysis.labels.quantity_label of the attrs. With a units attr, an EngFormatter with one SI prefix is set on each target axis. The prefix is striqt.waveform.units.si_prefix of the extent of the finite values, and is fixed for the axis. The prefixed units are in every tick label with tick_units True, or in the axis label with tick_units False, never in both. A label is set with or without finite values. The xarray plot unit label format is changed process-wide to 'Label (units)'.

Parameters:

  • which_axis (Literal['x', 'y', 'colorbar']) –

    'x', 'y', or 'colorbar'; the colorbar axis is the first colorbar of the figure

  • ax_data (Union[DataArray, Dataset]) –

    the array with the attrs that name the quantity and the values that select the prefix

  • coord_name (Optional[str], default: None ) –

    a coordinate of ax_data that supplies the attrs and values instead, or None

  • tick_units (bool | Literal['auto'], default: 'auto' ) –

    True places the prefixed units in each tick label and False in the axis label; 'auto' is True for a units attr of 1 or 2 characters

  • short (bool, default: True ) –

    True labels with standard_name; False labels with long_name when the attrs set one

  • ax (Optional[Axes | list[Axes]], default: None ) –

    the axes, or list of axes, to label; None labels the current axes, or every axes of fig when fig is given

  • fig (Optional[Figure], default: None ) –

    when given with ax None, an x or y label is set once as a figure super-label and the per-axes labels are hidden

Raises:

  • ValueError –

    if which_axis is not one of the 3 values, if a colorbar is requested and the figure has none, or if there are no axes to label

label_by_coord ¶

label_by_coord(
    data: DataArray,
    fmt: str,
    coord_or_dim: str = 'port',
    *,
    title_case: bool = True,
    **extra_fields: Any,
) -> list[str]

return fmt formatted once per value of coord_or_dim in data.

The fields of fmt are the coordinates on the dimension of coord_or_dim and extra_fields. The coordinate value is used when a coordinate and an extra field share a name. The xarray plot unit label format is changed process-wide to 'Label (units)'.

Parameters:

  • data (DataArray) –

    the array with the coordinates

  • fmt (str) –

    a str.format template; a numeric field accepts a prefix symbol spec ('{center_frequency:M}') or a float spec ('{center_frequency:.0f}')

  • coord_or_dim (str, default: 'port' ) –

    the coordinate or dimension that selects one entry per value

  • title_case (bool, default: True ) –

    True title-cases a lowercase string coordinate value

  • **extra_fields (Any, default: {} ) –

    further fields of fmt

Returns:

  • list[str] –

    one string per value of coord_or_dim

label_legend ¶

label_legend(
    data: Union[DataArray, Dataset],
    *,
    coord_name: str | None = None,
    tick_units: bool = True,
    ax: Optional[Axes] = None,
) -> Legend

add a legend with one entry per value of data and a title naming the quantity.

Numeric entries share one SI prefix. A string value is written as is. The xarray plot unit label format is changed process-wide to 'Label (units)'.

Parameters:

  • data (Union[DataArray, Dataset]) –

    the array or dataset with the attrs and values that label the legend

  • coord_name (str | None, default: None ) –

    a coordinate of data that supplies the attrs and values, or None for data itself

  • tick_units (bool, default: True ) –

    True ends each entry with the prefixed units; False ends the title with the prefixed units in parentheses and leaves each entry a bare mantissa

  • ax (Optional[Axes], default: None ) –

    the axes that receives the legend; None uses the current axes

Returns:

  • Legend –

    the matplotlib.legend.Legend added to ax
