striqt.sensor.peripherals¶

Peripheral controllers that a sweep sets up around each capture.

NoPeripherals ¶

NoPeripherals(spec: Sweep[Any, SP, SC, Any])

Bases: PeripheralsBase[SP, SC]

a Peripherals implementation for a sensor without peripheral hardware.

open, close, setup, and arm return None and access no device, and acquire returns an empty dict.

PeripheralsBase ¶

PeripheralsBase(spec: Sweep[Any, SP, SC, Any])

Bases: Peripherals[SP, SC]

base Peripherals implementation that opens on construction.

Construction reads the peripherals block of the sweep and calls open. Exit from the context manager calls close.
