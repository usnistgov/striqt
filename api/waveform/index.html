configure_cupy cached ¶

configure_cupy() -> None

set the cupy FFT plan cache size to 0 and disable the pinned-memory pool.

Both settings are global to the process: the cuFFT plan cache of the current device holds no plans, and each pinned host allocation is made by the CUDA driver rather than reused from a pool. The settings are applied once per process; later calls, and any call without cupy installed, return with no effect.

design_cola_resampler ¶

design_cola_resampler(
    fs_base: float,
    fs_target: float,
    bw: float = inf,
    bw_lo: float = 0,
    min_oversampling: float = 1.1,
    min_fft_size=2 * 4096 - 1,
    shift: ShiftType = False,
    window=None,
    fs_sdr: Optional[float] = None,
) -> ResamplerDesign

design the radio sample rate, LO offset, and COLA FFT sizes of a resampler.

nfft / nfft_out equals fs_sdr / fs_target exactly. The sizes are k * p and k * q for the reduced ratio p / q of fs_sdr to fs_target, with k the smallest even multiple of the COLA divisor of window that is 2·3·5·7-smooth and puts nfft_out above min_fft_size. Without fs_sdr, the radio rate is fs_base divided by the largest integer that keeps the rate at or above fs_target + min_oversampling * bw + bw_lo with shift, or at or above fs_target without. With shift, the radio is tuned lo_offset below the center frequency, and the magnitude of lo_offset is bw / 2 + bw_lo / 2 rounded up to a whole number of fs_sdr / nfft bins that is a multiple of the frames per hop of window.

Parameters:

  • fs_base (float) –

    the master clock rate (in S/s) that fs_sdr divides

  • fs_target (float) –

    the sample rate (in S/s) after resampling

  • bw (float, default: inf ) –

    the bandwidth (in Hz) to protect from LO leakage; inf disables the LO shift and leaves the passband unbounded

  • bw_lo (float, default: 0 ) –

    the bandwidth (in Hz) of the LO leakage and phase noise kept out of the protected band

  • min_oversampling (float, default: 1.1 ) –

    the factor applied to bw when sizing fs_sdr for an LO shift

  • min_fft_size –

    the size that nfft_out must exceed

  • shift (ShiftType, default: False ) –

    'left' or 'right' places the protected band below or above the tuned LO; 'none', None, or False leaves the LO at the center frequency

  • window –

    a key of the COLA window divisor table; None selects the divisor 1 for the sizes and the LO offset, and 'hann' in the result

  • fs_sdr (Optional[float], default: None ) –

    the radio sample rate (in S/s) to use instead of selecting one

Returns:

  • ResamplerDesign –

    the ResamplerDesign that resamples from the selected radio rate to

  • ResamplerDesign –

    fs_target

Raises:

  • ValueError –

    if shift is set while bw is infinite, shift is not a recognized direction, window has no COLA divisor, bw exceeds fs_base, the LO shift needs a radio rate above fs_base, no fraction with denominator up to OLA_MAX_FFT_SIZE realizes the rate ratio, or the LO shift does not fit the Nyquist band of the radio at fs_sdr

equivalent_noise_bandwidth ¶

equivalent_noise_bandwidth(
    window: WindowSpecType, N, fftbins=True, cached=True
)

return the equivalent noise bandwidth (ENBW) of a window, in bins.

One bin is fs / N wide for a window of N nonzero samples (Harris 1978). The ENBW in Hz is the returned value times fs / N. An FFT of the window zero-padded to N + nzero samples has bins of fs / (N + nzero). The same ENBW spans (N + nzero) / N times as many of those bins.

Parameters:

  • window (WindowSpecType) –

    the window name or (name, parameter) for get_window

  • N –

    the number of nonzero window samples

  • fftbins –

    the get_window periodic-window flag

  • cached –

    True designs the window through the cached get_window; False designs it uncached

Returns:

  • –

    the ENBW as a float: 1.0 for a rectangular window and larger for every other

References

F. J. Harris, "On the use of windows for harmonic analysis with the discrete Fourier transform," Proc. IEEE, vol. 66, no. 1, pp. 51-83, Jan. 1978.

get_window ¶

get_window(
    name_or_tuple: WindowType,
    nwindow: int,

    fftbins: bool = True,
    norm: bool = True,
    dtype: DTypeLike = 'float32',
    xp: XpType = None,
) -> Array

return a window of nwindow samples for xp, zero-padded to nwindow + nzero.

The design is cached in memory and on disk. A call that misses both runs the scipy window design and writes to the disk cache. Equivalent spellings of the arguments (a dtype given as a string or a numpy.dtype, xp given or omitted, positional or keyword nzero) share one cache entry. A numpy result is the cached array and must not be modified in place.

Parameters:

  • name_or_tuple (WindowType) –

  • nwindow (int) –

    the number of nonzero window samples

  • nzero (int, default: 0 ) –

    the number of zero samples appended to the window

  • fftshift (bool, default: False ) –

    True modulates the window by the half-band shift that puts the FFT of a windowed signal in ascending frequency order; the window is then complex when nwindow + nzero is odd

  • center_zeros (bool, default: False ) –

    True splits the nzero zeros before and after the window; False appends all nzero zeros after the window

  • fftbins (bool, default: True ) –

  • norm (bool, default: True ) –

    True scales the window to unit time-averaged power

  • dtype (DTypeLike, default: 'float32' ) –

    the floating-point precision of the result (the complex counterpart when fftshift makes the window complex); None keeps scipy's float64

  • xp (XpType, default: None ) –

    the array namespace of the result; None selects numpy

Returns:

  • Array –

    a 1-D array of nwindow + nzero samples in xp

oaresample ¶

oaresample(
    x: Array,
    up,

    scale: Array | float = 1.0,

resample x by up / down through STFT overlap-add.

Each STFT block of down samples is cropped or zero-padded to up bins, scaled by the low-pass response and scale, and overlap-added at the output rate. The response has the band edges of design_fir_lpf: the gain is 1/2 at filter_bandwidth / 2 and the transition is centered there.

Parameters:

    the waveform, with time on axis; its length must be a whole number of STFT hops, down + k * (down - noverlap)

  • up –

    the output block size (in samples), an even multiple of the COLA divisor of window

  • down –

    the input block size (in samples), an even multiple of the COLA divisor of window

  • fs –

    the sample rate (in S/s) of x

  • window (str | tuple[str, float], default: 'hann' ) –

    the COLA window of the STFT, a key of the divisor table

  • overwrite_x (bool, default: False ) –

    True permits the STFT to consume the buffer of x; the contents of x are undefined after the call

  • axis (int, default: 1 ) –

    the time axis of x

  • frequency_shift (float, default: 0 ) –

    the frequency (in Hz) moved to the output DC, a multiple of fs / down times the frames per hop of window; 0 keeps the center frequency

  • filter_bandwidth (float | None, default: None ) –

    the passband width (in Hz) of the low-pass; None or inf applies no low-pass

  • transition_bandwidth (float, default: 250000.0 ) –

    the width (in Hz) of the low-pass transition band

  • scale (Array | float, default: 1.0 ) –

    a voltage gain, a scalar or one value per entry of the axis before axis

  • out (Array | None, default: None ) –

    a C-contiguous buffer of at least x.size * up // down elements in the dtype of x that receives the output; x itself is accepted when overwrite_x is True

Returns:

  • –

    the waveform at fs * up / down on axis, of ``x.shape[axis] * up //

  • –

    down` samples, in the dtype and array namespace ofx; a view ofout`

  • –

    when out is given

Raises:

  • ValueError –

    if frequency_shift is nonzero while upsampling, is not a multiple of fs / down times the frames per hop, or moves the output band past an edge of the input band; if up or down is odd or not a multiple of the COLA divisor; if window has no COLA divisor; if filter_bandwidth is finite and at most transition_bandwidth; or if out is not C-contiguous, has another dtype, has fewer than x.size * up // down elements, or shares memory with x without overwrite_x

iq_to_cyclic_power ¶

iq_to_cyclic_power(
    x: Array,
    Ts: float,
    detector_period: float,
    cyclic_period: float,
    truncate=False,
    detectors=('rms', 'peak'),
    cycle_stats=('min', 'mean', 'max'),
    axis=0,
) -> dict[str, dict[str, Array]]

return cyclic statistics of the channel power of x binned along axis.

Each detector in detectors bins the power of x along axis into K samples of detector_period. The detector series is indexed as a matrix of cycles and lags: sample k is in cycle k // L at lag (k % L) * detector_period, where L = cyclic_period / detector_period is the number of detector bins per cycle and M = K / L is the number of cycles. Each cyclic statistic reduces the cycle axis, so the value at lag m summarizes the M samples at the same offset from the start of a cycle. The result spans one cyclic_period at the resolution of detector_period, with L samples per detector and statistic, for any capture length.

With a cyclic_period that is a common multiple of the periods of the expected signals (e.g., 10 ms for TDD cellular frames, 5 ms WiMAX frames, and the 1 ms pulse repetition interval of the SPN-43 radar), the features of those signals fall at the same lags in every cycle. Occupancy with an incommensurate period is spread across all lags. The uplink and downlink levels of a TDD network fall in disjoint lag windows.

With a mismatch dT between cyclic_period and the signal period, such as from a sample clock offset, a feature drifts by M * dT / detector_period lags over the capture and bleeds into neighboring lags. The drift stays within one lag while M * dT is below detector_period, which bounds the usable number of cycles M.

Parameters:

  • x (Array) –

    the IQ waveform, complex or real, with time on axis

  • Ts (float) –

    sample period of the waveform (in s)

  • detector_period (float) –

    duration of each power detector bin (in s), an integer multiple of Ts

  • cyclic_period (float) –

    duration of one cycle (in s), an integer multiple of detector_period

  • truncate –

    True to drop trailing samples that do not complete a detector bin or a cycle, and to round detector_period to the nearest multiple of Ts

  • detectors –

    power detector names accepted by iq_to_bin_power

  • cycle_stats –

    statistics accepted by stat_ufunc_from_shorthand, evaluated across cycles (names such as 'min', 'mean', 'max', or quantiles in (0, 1))

  • axis –

    the time axis of x

Returns:

  • dict[str, dict[str, Array]] –

    dict keyed on detector, of dicts keyed on cyclic statistic, of arrays in the

  • dict[str, dict[str, Array]] –

    namespace of x with the axis dimension replaced by the L cycle lags,

  • dict[str, dict[str, Array]] –

    in linear power units; each statistic is evaluated on the linear power

Raises:

  • ValueError –

    if detectors is None; if cyclic_period is not an integer multiple of detector_period; or, when truncate is False, if detector_period is not an integer multiple of Ts or the capture does not contain a whole number of cycles

References

D.G. Kuester et al., "Cyclic Analysis of Power in Radio Channels".
