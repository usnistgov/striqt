register the decorated function as the measurement configured by spec_type.

Registration mutates this registry when the decorator is applied. A sweep enables the measurement through an Optional[spec_type] field named name in an analysis group such as specs.BuiltinAnalyses.

The decorated function is called as func(x, capture, **spec.to_dict()) with x an array of shape (port, sample), and returns an array with axes dims or an (array, attrs) tuple. The returned wrapper is called as wrapper(iq, capture, as_xarray=True, **kwargs) with the fields of spec_type as keywords. The __signature__ of the wrapper and the {args} placeholder in the docstring are filled from spec_type. An array iq is passed to the function as x. From an AcquiredIQ, AcquiredIQ.preprocess selects x as prefer_filtered and prefer_aligned request. validate runs before the IQ is read and raises specs.helpers.SpecValidationError on a rejected combination. The wrapper returns, by as_xarray: True, an xarray.DataArray with a leading port dimension; 'delayed', a DelayedDataArray; False, the (array, attrs) pair.

correlate each port of the IQ against the 5G NR primary synchronization signal.

The input is the IQ before the analysis_bandwidth filter and before trigger alignment. The band at frequency_offset is shifted to baseband and resampled to sample_rate, then cross-correlated with the PSS sequence of each cell sector ID (3GPP TS 38.211 §7.4.2.2). Per capture, the output is the complex64 correlation (in √mW) with dimensions cellular_cell_id2, cellular_ssb_start_time (in s), cellular_ssb_beam_index, and cellular_ssb_lag (in s). The output keeps the first max_block_count sync blocks. A max_block_count of None keeps every block. The PSS template has unit energy over the 127 PSS subcarriers. The squared magnitude of a peak on a lag sample equals the received PSS symbol power. White noise with power spectral density N0 has a mean squared magnitude of N0 * subcarrier_spacing in each lag. The noise_bandwidth attr is subcarrier_spacing.

evaluate a spectrogram of each 5G NR SSB burst set by OFDM symbol and subcarrier.

The input is the IQ before the analysis_bandwidth filter and after trigger alignment. The STFT hops once per OFDM symbol. Half-subcarrier bins are summed pairwise to one bin per subcarrier of subcarrier_spacing. The frequency axis is trimmed to the sample_rate band about frequency_offset. Only the symbols of the burst set in the first 2 ms of each discovery_periodicity are kept (3GPP TS 38.213 §4.1).

Per capture, the output is power per subcarrier in dBm in a noise bandwidth of one subcarrier_spacing, with dimensions cellular_ssb_index (burst set within the capture), cellular_ssb_symbol_index (OFDM symbol within the burst set), and cellular_ssb_baseband_frequency (in Hz, relative to frequency_offset). Values are rounded to 3 decimals and stored as float16. The noise_bandwidth and resolution_bandwidth attrs follow the spectrogram measurement.

evaluate the cyclic-prefix autocorrelation of the IQ at each 4G or 5G symbol lag.

The input is the IQ after the analysis_bandwidth filter and before trigger alignment. For each spacing in subcarrier_spacings, the IQ is correlated with a copy of the IQ delayed by the OFDM symbol length, summed over the cyclic-prefix samples of the symbols that frame_range and symbol_range select. The downlink slots and the uplink slots of frame_slots are summed separately. Per capture, the output is the correlation magnitude in mW as float32 with dimensions (link_direction, subcarrier_spacing, cyclic_sample_lag). cyclic_sample_lag (in s) spans the longest symbol over the spacings. Entries past the symbol length of a spacing are nan, as is the 'uplink' row when frame_slots has no uplink slot. frame_range and symbol_range are a count of indexes from 0, or a (start, stop) pair as for the Python builtin range.

evaluate the fraction of resource grid elements in each power bin per link.

The input is the IQ before the analysis_bandwidth filter and after trigger alignment. A spectrogram with one bin per subcarrier (or per resource block, with average_rbs) and one hop per OFDM symbol is split into downlink and uplink symbols by frame_slots and special_symbols. Per capture, the output is float32 with dimensions link_direction and cellular_resource_power_bin (in dBm per bin bandwidth). The fractions of both link directions together sum to 1 on each port. Subcarriers inside the guard_bandwidths and flexible symbols are excluded from the count.

class striqt.analysis.specs.Tolerance(*, units, rtol, on_peak, off_peak_dBc=None)¶

Bases: SpecBase

the roundoff error budget of one measurement output.

The budget depends on the capture and the spec alone, not on the output values. on_peak bounds the error of the elements at the peak of the output. off_peak_dBc bounds the error of the other elements as a function of the level of each below the peak. Elements more than off_peak_dBc.peak below the peak are not bounded. The peak is the matched-filter bin of the matched input, e.g., the FFT bin at the frequency of a tone or the detector sample at the time of an impulse.

Parameters:

  • units (str) – units of on_peak: ‘dB’, or the linear units of the output

  • rtol (float) – relative error bound on each output value, as a ratio

  • on_peak (ErrorBound) – absolute error bound, in units, on the elements at the peak of the output

  • off_peak_dBc (ErrorBound | None) – levels below the output peak, as negative values, at which the rms and the worst-case amplitude errors equal the amplitude of the element, or None to apply on_peak to every element (Constraints: units: dBc)
