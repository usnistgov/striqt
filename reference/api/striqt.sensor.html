striqt.sensor¶

striqt.sensor.iterate_sweep(resources: Resources[SS, SP, SC, SA, PS, PC], *, always_yield: bool = False, yield_values: bool = True, loop: bool = False, **replace: Unpack[AnyResources[SS, SP, SC, SA, PS, PC]]) → Generator[Dataset | DelayedDataset | None, None, None]¶

run the iterate of resources['runner'] over resources.

Parameters:

  • resources – the open resources of open_resources

  • always_yield – with yield_values False, True yields None at every step and False yields nothing

  • yield_values – True yields the sink result of every step

  • loop – True cycles through the captures from the first after the last

  • **replace – entries that replace those of resources for this run

Yields:

the return value of sink.append for each capture, or None at the steps before the first sink write; with yield_values False, None at every step or nothing as always_yield selects. The iteration never ends when loop is True.

striqt.sensor.open_resources(spec: specs.ActionSpec[SS, SP, SA], spec_path: str | Path | None = None, *, test_only: bool = False, on_source_opened: SourceOpenCallback | None = None, on_analyzed: AnalyzedCallback | None = None, on_sink_cached: CachedCallback | None = None) → ConnectionManager[SS, SP, SC, SA, PS, PC]¶

open the sensor hardware and software contexts needed to run spec.

The source, peripherals, sink, calibration file, and log file open concurrently for the sweep of the action runner built from spec. The compute warmup runs in the calling thread. The returned ConnectionManager yields the open Resources on entry and closes every resource on exit. An exception from a hook ends the run. Progress is logged at INFO on the sweep logger.

Parameters:

  • spec – the action spec

  • spec_path – the file from which spec was read, or None; sets the process working directory and the {spec_path} path field

  • test_only – if True, open NoPeripherals in place of the peripherals and skip the compute warmup

  • on_source_opened – hook run once with (sweep, source_id) in a worker thread after the source opens and before the first capture

  • on_analyzed – hook run in the analysis thread with the DelayedDataset of each capture, before the sink receives the dataset

  • on_sink_cached – hook run in the analysis thread with (resources, cache, capture, result, **kwargs) each time a measurement fills a KwArgCache

Raises:

  • TypeError – if no action runner is registered for the type of spec

  • KeyError – if no sensor binding is registered for the type of spec

  • ExceptionGroup – if more than one resource fails to open; a single failure raises that exception

striqt.sensor.open_store(spec: specs.ZarrSink, *, format_path: specs.paths.PathFormatter | None = None, force=False) → ZarrStore¶

open the zarr store at spec.path for appending.

The suffix of the path is set to .zarr for a directory store and .zarr.zip for a zip store. Missing parent directories are created.

Parameters:

  • spec – the sink block with the path and store type

  • format_path – expands the {fields} of spec.path; None leaves the path as is

  • force – if True, truncate an existing store; if False, append

Raises:

ValueError – if spec.path is None

decode the action spec in the json file at path.

The file has the schema of a yaml spec without !include directives. The extensions block of the file is imported before decoding. A relative extensions.import_path is resolved against the directory of the file.

Parameters:

  • path – the json file

  • type – the action spec type to decode into, or None to select the type bound under the sensor_binding tag

  • output_path – replaces sink.path in the returned spec when given

  • store_backend – replaces sink.store of a Sweep spec when given

Returns:

an instance of type, or of the bound class when type is None

Raises:

  • msgspec.ValidationError – if the file does not validate as the spec class, or if the tag names no registered binding

  • TypeError – if store_backend is given and the sink of the spec is not a ZarrSink

  • FileNotFoundError – if extensions.import_path does not exist

striqt.sensor.read_zarr_spec(path: str | Path, *, type: type[ActionSpec] | None = None, output_path: str | None = None, store_backend: str | None = None, extension_root: str | Path | None = None) → ActionSpec¶

decode the sweep spec saved in the attrs of the zarr store at path.

The extensions block of the attrs is imported before decoding. Only the attrs that name fields of the sweep class, the sensor_binding tag, and mock_source are read. An extensions.sink attr is dropped with a DeprecationWarning.

Parameters:

  • path – the zarr store, a .zarr directory or .zarr.zip archive

  • type – the sweep class to decode against, or None to select the class bound under the saved sensor_binding tag; a saved mock_source attr selects the mock class of that binding instead

  • output_path – replaces sink.path in the returned spec when given

  • store_backend – replaces sink.store of a Sweep spec when given

  • extension_root – the directory against which a relative extensions.import_path is resolved, or None for the directory of the store

Returns:

an instance of type, or of the bound sweep class when type is None

Raises:

  • msgspec.ValidationError – if the attrs do not validate as the sweep class, or if the tag names no registered binding

  • TypeError – if store_backend is given and the sink of the spec is not a ZarrSink

  • FileNotFoundError – if extensions.import_path or extension_root does not exist

striqt.sensor.bindings.bind_sensor(key: str, sensor: Sensor[TS2, TP2, TC2], schema: Schema[SS, SP, SC, SA, PS, PC], register: bool = True, *, module: str | None = None) → type[Controller[SS, SP, SC, SA, PS, PC]]¶

bind the implementation classes of a sensor to spec types under key.

The returned Controller subclass has the class attributes sensor (a SensorBinding) and schema. Its sensor.sweep_spec_cls is a subclass of the action spec type, tagged with key in the sensor_binding field. In that subclass, source, peripherals, captures (when the action declares the field), and analysis (when the action is a Sweep) are annotated with the types in schema. A sweep file with sensor_binding equal to key decodes to an instance of that subclass. The tagged subclass has the class attributes sensor, schema, controller (the returned class), and sweep_cls (the bound Sweep class with the same spec types, or the tagged subclass when the action is a Sweep). The tagged subclass of an unregistered binding is decoded only by explicit type.

Parameters:

  • key – the sensor_binding value of sweep files, and the registry key

  • sensor – the implementation classes; the sensor of an existing controller binds the same hardware for the action in schema

  • schema – the spec types; schema.action selects the action spec type and schema.analysis the analysis group

  • register – if True, make the binding available by key to get_controller and the tagged subclass an arm of the union from get_tagged_sweep_type
